  <h1>隐私声明</h1>
  <p class="meta">更新日期：2026年9月30日</p>
  <p>本声明说明 EAIS LAB（边缘智能实验室）网站 eaislab.com 在浏览、联系和内容管理过程中涉及的信息处理。通过本站链接访问的其他网站适用其各自的隐私声明。</p>

  <h2>网站浏览与公开信息</h2>
  <p>本站用于展示实验室研究、成员、成果及招生信息。普通浏览无需注册；当前公开页面未配置访客统计或广告跟踪脚本，也不提供在线申请或材料上传表单。论文搜索和筛选在浏览器内完成，不向本站服务器提交搜索词。</p>
  <p>成员页面包含姓名、研究方向、照片、学术链接及部分联系方式；校友页面还展示毕业论文题目和毕业去向。这些内容可被公众访问、搜索引擎收录或缓存。如相关个人信息需要更正或移除，请通过下方邮箱联系。</p>

  <h2>托管、图片与地图服务</h2>
  <ul>
    <li>网站由 GitHub Pages 托管，部分图片由 Cloudflare Images 提供。加载页面或图片时，服务提供方可能处理 IP 地址、浏览器信息、请求时间及请求资源等技术信息，用于交付内容、运行维护和安全防护。</li>
    <li>联系页面嵌入 Google 地图。地图加载时，浏览器会连接 Google，其服务可能接收 IP 地址、浏览器信息及来源信息，并按自身设置使用 Cookie 等技术。地图展示预设地址，本站不主动请求设备定位权限。</li>
    <li>第三方服务的信息处理和保存期限由其政策及服务设置决定，可能涉及在您所在国家或地区之外处理信息。请参阅 <a href="https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement">GitHub 隐私声明</a>、<a href="https://www.cloudflare.com/privacypolicy/">Cloudflare 隐私政策</a>和 <a href="https://policies.google.com/privacy">Google 隐私政策</a>。</li>
  </ul>

  <h2>邮件联系与申请材料</h2>
  <p>点击邮箱链接会打开您的邮件工具。发送邮件后，收件方及邮件服务商会处理您提供的姓名、邮箱、邮件内容和附件；实验室使用这些材料开展相应的咨询、招生或合作沟通。请仅提交与事项有关的资料，勿通过公开网站仓库或公开链接提交私人申请材料。有关邮件资料的保存或删除问题，请联系收件方。</p>

  <h2>管理员登录与浏览器存储</h2>
  <p>管理员入口使用 Decap CMS，通过 GitHub 授权登录，并使用 Cloudflare Workers 提供登录及图片管理服务；后台程序从 UNPKG 加载。登录后的身份信息和访问令牌会保存在浏览器本地存储中，用于权限校验、内容维护和图片上传。此流程仅供授权管理员使用，普通浏览无需登录。</p>
  <p>管理员发布的内容存入 GitHub 仓库，上传的图片存入配置的图片服务。公开内容可能保留在版本历史和第三方缓存中，修改当前页面不等于删除所有历史副本。您可以通过浏览器设置限制第三方 Cookie 或清除站点数据，但这可能影响地图或后台登录功能。</p>
